# yacloud

Скрипт для автоматического резервирования публичных IP-адресов в Yandex Cloud с нужным префиксом подсети.

Перебирает зоны доступности (ru-central1-a/b/d), создаёт IP, проверяет первые два октета. Если не совпали — удаляет и пробует снова. Останавливается, когда найден IP из подсети `51.250.x.x` или `84.201.x.x`.

## Требования

- Python 3.11+
- Playwright для Python

## Установка

```bash
pip install playwright
python -m playwright install chromium
```

## Запуск

```bash
python3 reserve_ip.py
```

1. Откроется браузер с консолью Yandex Cloud
2. Залогинься вручную (сессия сохраняется в `./browser_data/`, повторный логин не нужен)
3. Нажми **Resume** в окне Playwright Inspector
4. Скрипт начнёт перебор — в консоли будут выводиться получаемые IP
5. Когда найдётся подходящий IP — скрипт остановится, браузер останется открытым

## Настройка

В начале `reserve_ip.py`:

- `FOLDER_URL` — ссылка на страницу IP-адресов вашего каталога
- `ZONES` — список зон доступности для перебора
- `TARGET_PREFIXES` — целевые префиксы IP (первые два октета)
- `MAX_ATTEMPTS` — максимальное количество попыток
